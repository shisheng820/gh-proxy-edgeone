Usage

Release or archive:

/https://github.com/user/repo/releases/download/v1.0.0/file.zip

Raw file:

/https://raw.githubusercontent.com/user/repo/refs/heads/main/README.md

Query shortcut:

/?q=https://raw.githubusercontent.com/user/repo/refs/heads/main/README.md

Routing Model

  • / and static files are served from public/.
  • /api/health is a dedicated function route.
  • GitHub, raw.githubusercontent, gist and archive targets are proxied by middleware.
